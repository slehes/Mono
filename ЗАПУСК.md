# Запуск Mono

## Структура проекта

```
Mono/
├── mono-backend/        ← Python FastAPI бэкенд
│   ├── main.py
│   ├── requirements.txt
│   ├── routers/         ← auth, search, tracks, artists, albums, playlists, likes, radio, landing
│   ├── services/        ← yandex_client.py (singleton ClientAsync)
│   └── models/          ← Pydantic модели
└── MonoApp/             ← iOS приложение
    ├── project.yml      ← xcodegen конфиг
    └── Mono/            ← Весь Swift код
        ├── Glass/       ← LiquidGlass обёртки
        ├── Models/
        ├── Services/
        ├── ViewModels/
        ├── Views/
        └── Assets.xcassets/  ← Твой логотип + AppIcon
```

## Шаг 1 — Запустить бэкенд

```bash
cd mono-backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

## Шаг 2 — Сгенерировать Xcode проект

```bash
# Установи xcodegen (один раз)
brew install xcodegen

# Генерируй проект
cd MonoApp
xcodegen generate
```

## Шаг 3 — Открыть в Xcode

```bash
open MonoApp/Mono.xcodeproj
```

1. Выбери симулятор iPhone 16 (iOS 16+)
2. Нажми Run (⌘R)
3. На экране авторизации нажми "Войти через Яндекс"
4. Перейди по ссылке, введи код — и всё!

## Важные детали

- **Бэкенд должен работать** на `localhost:8000` пока используешь симулятор
- **MP3 ссылки живут ~60 сек** — при зависании буфера плеер автоматически запрашивает новый URL
- **Без Яндекс Плюс** — превью 128kbps, **с Плюс** — полные треки 320kbps
- **LiquidGlass** на iOS 26+ использует нативный `UIGlassEffect`, на 16-25 — Metal шейдер

## API эндпоинты бэкенда

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/auth/device-code` | Получить код Яндекс Device Flow |
| POST | `/api/auth/poll-token?session_id=` | Проверить статус авторизации |
| GET  | `/api/tracks/{id}/stream` | **Свежий** прямой MP3 URL (никогда не кэшировать!) |
| GET  | `/api/landing` | Главная: чарт + рекомендации + новые релизы |
| GET  | `/api/search?q=` | Поиск треков/артистов/альбомов |
| GET  | `/api/likes/tracks` | Лайкнутые треки |
| POST | `/api/likes/tracks/{id}` | Лайкнуть трек |
| DELETE | `/api/likes/tracks/{id}` | Убрать лайк |
| GET  | `/api/artists/{id}` | Детали артиста |
| GET  | `/api/artists/{id}/tracks` | Треки артиста |
| GET  | `/api/albums/{id}` | Альбом с треками |
| GET  | `/api/playlists/{uid}/{kind}` | Плейлист с треками |
| GET  | `/api/radio/{station_id}/tracks` | Радио-треки |

Все запросы требуют заголовок `Authorization: Bearer <yandex_token>`
